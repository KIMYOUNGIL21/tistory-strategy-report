# AI 음악 채널 만드는 비용: 실제 사용 도구 기준

> 타깃 질의: `ai 음악 채널 비용`, `suno 비용`, `유튜브 ai 채널 시작 비용`
> 카테고리: 시작 체크리스트
> 상태: **골격만(2026-07-20), 발행 불가 — 실제 비용 입력 대기**
> 검증 메모: 8번 글(`08-자동-리포트.md` 129~137행)에 이미 GitHub Actions·텔레그램·YouTube API·Cloudflare Workers·OpenAI API 표가 있음(자동화 비용). 이 글은 그것과 겹치지 않게 **"채널을 시작하는 데" 드는 비용**(Suno 구독, 편집 도구 등)에 집중하고, 자동화 비용은 8번을 인용만 한다.

---

**시작 체크리스트**

[입력] 훅 문장 — 총 월 비용 합계가 나오면 그걸로 두괄식 훅을 만들 수 있음("채널 3개 굴리는 데 한 달에 OOO원 씁니다" 같은 형태)

### 필요한 답변

1. Suno 구독료 — 이미 확정(프로 플랜, 월 15,000원, [[05-suno-요금제-비교]]). 그대로 인용.
2. 영상 편집/자막/썸네일 제작에 쓰는 도구가 있나요? 있다면 이름과 대략의 비용(무료면 무료로).
3. 썸네일 이미지는 어떻게 만드나요? (AI 이미지 생성 도구를 쓴다면 이름·비용)
4. 8번 글의 OpenAI API 비용(자동화용)을 이 글에서도 합산할지, 아니면 "자동화 비용은 별도 글([[08-자동-리포트]])에" 정도로만 링크할지.
5. 도메인·기타 구독 서비스가 더 있나요?
6. 이 비용을 "채널 1개 기준"으로 낼지 "3채널 합산"으로 낼지 — 3채널이 Suno 구독 하나를 공유하는 구조([[01-suno-사용법-2026]])라 1개 기준으로 내면 오해 소지가 있음. 3채널 합산 + "채널이 늘어도 Suno 비용은 안 늘어난다"는 포인트를 살리는 쪽을 권장.

### 예상 구조 (답변 받으면 채울 것)

1. 뭐가 드나 — 표 하나로 (Suno + 편집 도구 + 썸네일 도구 + 자동화 비용 링크)
2. 채널이 늘어도 안 느는 비용 vs 느는 비용
3. 처음 시작할 때와 지금, 비용이 달라진 부분
4. 무료로 대체 가능한 항목 vs 유료가 나은 이유가 있는 항목
