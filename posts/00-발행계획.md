## 발행 역할 분담 (2026-07-17 확정)

**Claude는 비공개 저장까지만. 예약·발행은 사용자가 직접 건다.**

이유: 티스토리 발행 창은 공개로 바꾸는 순간 발행일이 "현재"로 잡히고, 날짜를 바꾸기 전에 발행을 누르면 즉시 공개된다. 그런데 이 날짜 지정 버튼이 브라우저 자동화에 반응하지 않는다(좌표 클릭·요소 클릭·이벤트 강제 발생 전부 실패, 사람이 누르면 정상). 자동화가 억지로 시도하면 즉시 발행 사고만 남는다. 또 **비공개로 전환하면 기존 예약이 삭제된다** — 이미 예약된 글을 수정할 때는 공개/예약 설정을 건드리지 말고 본문만 저장할 것.

작업 후에는 "어느 글을 언제로 예약" 목록을 정리해 넘긴다.

### 1,164명 숫자 처리 (결론: 1,164 유지 + 맥락 명시)

중년가요방 802명은 원래 다른 용도로 쓰던 채널의 기존 구독자이고, 지금 AI 음악 채널로 전환하는 중이다. 즉 **AI 음악으로 두 달간 맨바닥에서 모은 구독자는 그밤라디오 298 + 트로트TV 64 = 362명**이 맞다.

중년가요방 802명은 원래 다른 용도로 쓰던 채널의 기존 구독자이고, 지금 AI 음악 채널로 전환하는 중이다. AI 음악으로 두 달간 맨바닥에서 모은 구독자는 그밤라디오 298 + 트로트TV 64 = 362명.

**처리 결과(사용자 결정)**: 1,164명은 현재 3채널 합계로 사실이므로 그대로 유지. 대신 (a) 틀린 "50배 차이" 분석은 삭제, (b) 중년가요방이 전환 중인 채널이고 802명은 전환 전 구독자라는 한 줄을 표 아래 명시, (c) 유효 비교군인 그밤라디오(영상당 6명) vs 트로트TV(영상당 1.6명) 3.7배 차이로 교체. 3번 글·다섯 줄 요약 반영 완료.

**교훈: 사용자가 준 숫자도 맥락을 물어야 한다.** 합이 1,164와 맞아떨어지자 검증이 끝났다고 판단하고 바로 해석(50배 차이)까지 붙여 발행했다. 숫자의 출처와 성격을 안 물은 게 원인.

### 이 과정에서 확인된 두 가지 (중요)

1-a. **동기화 격차 재확인(2026-07-17, 5번 글 편집 중 발견).** ① 티스토리 5번 글에는 **대표 이미지(타이틀 카드, "Suno 요금제 비교 / 무료와 유료의 실제 차이" 디자인)**가 붙어 있는데 마크다운에는 기록이 없다. 다른 글도 마찬가지일 가능성이 높다 — 확인 필요. ② 크레딧 섹션 본문이 마크다운과 문장 단위로 달랐다(티스토리는 "숫자만 보면 감이 안 오니, 실사용 기준으로 환산해보겠습니다"로 시작). 즉 **마크다운은 티스토리의 사본이 아니라 별개로 갈라진 버전**이다. 검수는 반드시 실제 글 기준으로 할 것.
1-b. **티스토리 편집 방법(재현 가능, 5번 글에서 검증).** 편집기 URL은 `https://ai-pd.tistory.com/manage/newpost/{entryId}?type=post&returnURL=%2Fmanage%2Fposts%2F`. entryId는 글 관리 목록의 체크박스 id(`inpCheck7` → 7)에서 얻는다. 본문은 TinyMCE — `window.tinymce.get('editor-tistory')`로 접근해 `getDoc().body.children`을 직접 수정한 뒤 `fire('change')` + `setDirty(true)`. 저장은 "완료" → 발행창에서 **설정을 건드리지 말고** "공개 발행" 클릭 → 발행일이 미래면 예약이 그대로 유지된다(목록에서 재확인함). 5번 글 = entry 7.
1. **마크다운 ≠ 티스토리.** 티스토리 실제 글에는 각 글마다 스크린샷 1장과 내부 링크가 이미 들어가 있었으나 로컬 마크다운에는 없었음. QA의 "스크린샷 0장·내부 링크 0개" 지적은 이 동기화 격차 탓(검수 대상이 마크다운이었음). **앞으로 티스토리에서 직접 편집한 내용은 반드시 마크다운에 역반영할 것.** 각 글의 기존 캡처: 2번=유튜브 고객센터 정책 페이지, 3번=Suno 작업공간, 4번=Suno 요금제 비교표(Commercial rights), 5번=Suno 요금제 화면.
