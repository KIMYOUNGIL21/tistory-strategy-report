# 티스토리 × AI 음악 전자책 퍼널 전략

> 기준일: 2026-07-16
> 목표: 검색 유입 → 카카오 오픈채팅 → 그로블 무료판 → 39,000원 유료 전자책 전환

## 결론부터

**티스토리는 시작해도 된다. 다만 블로그 2개를 동시에 시작하지 말고, 90일 동안 1개만 운영하는 것이 맞다.**

첫 블로그는 `Suno 사용법` 같은 검색형 정보와 실제 AI 음악 채널 운영 기록을 한 도메인 안의 두 카테고리로 묶는다. 티스토리를 장기 본진이나 애드센스 사업으로 보지 않고, 이미 가지고 있는 실제 경험을 검색 유입과 리드로 바꾸는 **저비용 검증 채널**로 사용한다.

90일 뒤 검색 유입과 오픈채팅 전환이 확인되면 정보형 카테고리를 두 번째 블로그로 분리한다. 검증 전부터 두 블로그로 나누면 글 수, 검색 신뢰도, 내부 링크, 운영 체력이 모두 반으로 갈라진다.

핵심 우선순위는 다음과 같다.

1. 전자책 잠재고객 확보
2. 검색되는 콘텐츠 자산 축적
3. 실제 운영 기록을 통한 신뢰 형성
4. 애드센스는 트래픽이 생긴 뒤 붙는 부수입

## 1. 왜 이 전략인가

### 티스토리는 여전히 쓸 수 있지만 플랫폼 리스크가 커졌다

- 티스토리는 2023년부터 수익형 블로그 본문 상단 또는 하단에 자체 광고 1개를 추가하고 있다. 운영자가 임의로 제거할 수 없으며, 운영자의 기존 광고와 별도로 노출된다. [티스토리 자체 광고 공식 공지](https://notice.tistory.com/2646)
- 2026년에는 직접 동영상 업로드를 중단하고 기존 동영상도 정리하기 시작했다. 티스토리 공식 설명에 따르면 직접 업로드 동영상은 전체 글의 약 1%였지만 운영 자원은 많이 필요했다. [동영상 업로드 기능 조정 공지](https://notice.tistory.com/2696)
- 2026년 6월 29일부터 카카오 애드핏 신규 연동 신청이 종료됐다. 기존 연동은 유지되며 Google AdSense 등 다른 광고 플랫폼 연동은 계속 가능하다. [티스토리 운영 정책 공지 목록](https://notice.tistory.com/category/%EC%9A%B4%EC%98%81%20%EC%A0%95%EC%B1%85%20%EC%95%88%EB%82%B4)
- 포털 다음 운영사 AXZ는 2026년 5월 업스테이지에 인수됐다. 업스테이지는 다음을 AI 포털로 재구성하겠다고 밝혔다. 검색과 콘텐츠 정책이 바뀔 가능성이 있으므로 다음 유입 하나에 의존하면 안 된다. [업스테이지 공식 발표](https://www.upstage.ai/ko/news/upstage-axz-acquisition-final)

이 변화가 곧 티스토리 종료를 뜻하지는 않는다. 다만 **플랫폼에 원본과 고객 관계를 전부 맡기지 말아야 한다는 신호**로 보기에는 충분하다.

따라서 다음 안전장치를 처음부터 둔다.

- 개인 도메인을 연결해 나중에 다른 플랫폼으로 옮길 수 있게 한다.
- 모든 글의 원본을 Notion 또는 Markdown으로 별도 보관한다.
- 고객 접점은 티스토리 구독자가 아니라 오픈채팅, 그로블 구매자, 향후 이메일 목록으로 옮긴다.
- 다음 검색은 초기 보너스로 보고, 구글·네이버 색인과 직접 유입을 함께 만든다.

### 애드센스보다 전자책 퍼널이 먼저다

Google은 애드센스 승인에 필요한 공식 글 개수나 글자 수를 제시하지 않는다. 공식 기준은 독창적이고 품질이 높으며 실제 독자를 끌어들이는 콘텐츠다. [AdSense 자격 요건](https://support.google.com/adsense/answer/9724?hl=ko)

따라서 `글 20개 → 애드센스 신청` 같은 공식을 목표로 삼지 않는다. 내부 준비 기준으로 20편 이상을 사용할 수는 있지만, 신청 조건으로 오해하면 안 된다. 다음 상태가 먼저 갖춰져야 한다.

- 사이트 주제가 한 문장으로 설명된다.
- 운영자가 직접 실행한 화면, 수치, 실패와 수정 내용이 들어 있다.
- 소개, 연락처, 개인정보처리방침, 카테고리 구조가 완성돼 있다.
- 주요 글이 검색엔진에 색인되고 실제 검색 노출이 발생한다.
- AI 초안을 그대로 발행하지 않고 운영자의 경험과 검증이 추가된다.

이 프로젝트에서 광고 수익보다 전자책 1건 판매의 가치가 훨씬 크다. 애드센스 때문에 광고를 늘려 CTA를 방해하면 본래 사업 목표를 훼손한다.

## 2. 블로그 구조

### 1단계: 블로그 하나, 카테고리 두 개

추천 포지셔닝 문장:

> AI 음악 채널 3개를 직접 운영하는 그밤PD가 Suno 사용법, 제작 자동화, 실패와 실제 운영 기록을 공개하는 곳

추천 임시 이름:

- 그밤PD의 AI 음악 실험실
- AI 음악 채널 운영일지
- Suno로 채널 만드는 사람

이름에는 `부업`, `월 천만 원`, `자동 수익`처럼 강사형 시장에서 남용된 표현을 넣지 않는다.

| 카테고리 | 역할 | 독자가 검색하는 것 | 글의 증거 |
|---|---|---|---|
| Suno 실전 매뉴얼 | 검색 유입 | 사용법, 가격, 프롬프트, 저작권, 오류 | 실제 화면, 직접 만든 곡, 설정값 |
| AI 음악 채널 운영일지 | 신뢰·전환 | 수익 현실, 조회수, 실패, 자동화, 제작 과정 | 3채널 운영 로그, 성적표, 수정 전후 |
| 시작 체크리스트 | 허브 | 처음부터 따라 하기 | 무료판 일부, 단계별 내부 링크 |
| 도구·템플릿 | 재방문 | 프롬프트, 체크리스트, 파일 구조 | 직접 쓰는 템플릿 |

### 두 번째 블로그를 여는 조건

다음 조건을 모두 만족한 뒤 정보형 블로그 분리를 검토한다.

- 첫 블로그에 품질 검수된 글이 30편 이상 있다.
- 정보형과 운영일지형의 검색어·독자 행동이 실제로 다르게 나타난다.
- 주 3편을 발행해도 기존 블로그 업데이트가 멈추지 않는다.
- 오픈채팅 입장 또는 무료판 다운로드가 검색 글에서 발생한다.
- 분리 후에도 각 블로그에 최소 주 1편을 유지할 소재가 있다.

분리한다면 역할은 이렇게 나눈다.

- 블로그 A: 그밤PD 운영일지 — 사람, 신뢰, 실패, 숫자, 브랜드
- 블로그 B: Suno 실전 매뉴얼 — 검색 질의, 문제 해결, 비교, 업데이트

## 3. 키워드 전략

### 유입의 첫 축은 `AI 부업`이 아니라 `Suno 문제 해결`이다

중단된 Claude 조사에서 네이버 데이터랩의 2025-01~2026-07 비교 데이터를 확인했다. 동일 비교 안에서 `수노/Suno/Suno AI` 그룹이 `AI 부업`, `유튜브 수익화`, `AI 커버`보다 훨씬 높은 상대 검색지수를 보였다. 이 값은 절대 검색량이 아니라 선택한 키워드 그룹 안의 상대지수이며, 2026년 7월 값은 월이 끝나지 않은 부분 데이터이므로 방향 판단에만 사용해야 한다.

실행 우선순위는 다음과 같다.

1. **도구 사용 질의**: Suno 사용법, 가격, 크레딧, 다운로드, 프롬프트
2. **권리·수익화 질의**: 저작권, 상업적 이용, 유튜브 수익화, AI 표시
3. **문제 해결 질의**: 한글 발음, 곡이 짧게 나옴, 보컬 깨짐, 스타일 오류
4. **완성 목표 질의**: AI 노래 만들기, AI 음악 유튜브 채널, 플레이리스트 제작
5. **경험 질의**: 실제 수익, 조회수 안 나오는 이유, 실패 후기, 비용 공개

12. 무료 전자책에 넣지 못한 실제 운영 체크리스트

### 글 한 편의 기본 구조

1. 검색 질문에 대한 3~5줄 답
2. 이 글을 쓸 자격이 되는 실제 경험
3. 단계별 설명
4. 직접 실행 화면·수치·실패 사례
5. 흔한 오해 또는 실패 조건
6. 관련 글 2~3개 내부 링크
7. 독자의 다음 단계에 맞는 CTA 하나
8. 작성일과 마지막 검증일

Google은 검색엔진용 대량 콘텐츠보다 독자에게 도움이 되는 콘텐츠, 직접 경험, 명확한 출처를 강조한다. AI 사용 자체가 금지된 것은 아니지만 가치 없는 페이지를 대량 생성하면 스팸 정책에 걸릴 수 있다. [생성형 AI 콘텐츠 가이드](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content?hl=ko), [사람 중심 콘텐츠 가이드](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko)

## 4. 검색엔진 운영

### 구글

- Google Search Console을 개설 즉시 연결한다.
- 검색 질의 하나에 글 하나를 대응시키고 제목을 명확하게 쓴다.
- 같은 답을 표현만 바꿔 여러 글로 만들지 않는다.
- 실제 화면, 전후 비교, 체크리스트처럼 AI 요약이 대체하기 어려운 자산을 넣는다.
- 정보형 글에서 운영일지로, 운영일지에서 시작 체크리스트로 내부 링크를 연결한다.

AI Overview가 나타나는 정보성 검색에서는 클릭률이 낮아지는 경향이 확인됐다. 다만 2026년 Seer Interactive 연구에서는 AI Overview에 출처로 인용된 브랜드가 인용되지 않은 브랜드보다 높은 클릭률을 보였고, 일부 구간은 회복되기도 했다. 따라서 짧은 정의문만 양산하기보다 **인용될 만한 원본 데이터와 실제 사례**를 제공해야 한다. [Seer Interactive 2026 연구](https://www.seerinteractive.com/insights/aio-impact-on-google-ctr-2026-update)

### 네이버

`티스토리는 네이버에 절대 노출되지 않는다`고 단정할 근거는 없다. 네이버는 외부 웹사이트를 수집·색인하며 웹마스터도구에서 RSS와 사이트맵 제출, 수집 상태 확인을 지원한다. 다만 네이버 자체 블로그와 동일한 노출을 기대하기보다는 웹문서 유입 채널로 관리한다.

- 네이버 서치어드바이저에 사이트를 등록한다.
- RSS와 사이트맵을 제출한다.
- 색인 누락과 robots 설정을 확인한다.
- 대표 제목과 설명을 짧고 명확하게 설정한다.

참고: [네이버 사이트 진단](https://searchadvisor.naver.com/guide/diagnose-site), [RSS·사이트맵 제출](https://searchadvisor.naver.com/guide/request-feed)

### 다음

다음 노출은 초기 유입이 빨리 생길 수 있는 채널이지만 통제하기 어렵다. 다음 검색 누락 사례는 존재하지만, 개인 경험담을 일반 규칙처럼 사용하지 않는다.

- 발행 초기에 유사 글을 짧은 시간에 대량 등록하지 않는다.
- 두 블로그에 같은 글을 복사하지 않는다.
- 과도한 키워드 반복, 낚시성 제목, 본문과 무관한 홍보를 피한다.
- 다음 유입 비중이 커져도 콘텐츠와 고객 목록을 외부에 백업한다.

## 5. CTA와 전환 퍼널

### 외부 링크 자체를 두려워할 필요는 없다

Google 공식 가이드는 맥락 있는 외부 링크가 출처와 신뢰를 보여줄 수 있다고 설명한다. 외부 링크가 있다는 이유만으로 검색 노출이 불리해진다고 볼 근거는 없다. 문제는 링크의 존재보다 글이 독자의 질문을 해결하지 못하고 판매 페이지로만 보내는 경우다. [Google 링크 권장사항](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)

### CTA는 글마다 하나만 둔다

권장 흐름:

```text
검색 글
  → 관련 운영 기록 또는 시작 체크리스트
  → "AI 음악 채널 시작 체크리스트" CTA
  → 카카오 오픈채팅
  → 그로블 0원 무료판
  → 운영 로그와 질문 수집
  → 방 50명 후 유료판 출시
```

모든 글에서 곧바로 `전자책 구매`를 외치지 않는다.

| 독자 상태 | 적절한 CTA |
|---|---|
| 단순 사용법 검색 | 관련 글 또는 체크리스트 |
| 채널 시작을 고민 | 무료판 + 오픈채팅 |
| 직접 운영 중이며 막힘 | 운영 로그방 + 질문 접수 |
| 무료판을 읽고 실행 의지 있음 | 유료판 대기 또는 출시 안내 |

CTA 예시:

> 저도 처음에는 무엇부터 해야 할지 몰라 같은 실수를 반복했습니다. 제가 실제로 쓰는 `AI 음악 채널 시작 체크리스트`와 무료판은 오픈채팅에서 받을 수 있습니다. 판매방이 아니라 자료 수령과 실제 운영 로그를 보는 방입니다.

### 추적할 링크

글마다 링크를 구분한다.

```text
?utm_source=tistory
&utm_medium=blog
&utm_campaign=ebook_free
&utm_content=suno_copyright
```

최소 기록 항목:

- 글 URL
- 검색 유입 수
- CTA 클릭 수
- 오픈채팅 입장 수
- 그로블 무료판 다운로드 수
- 유료판 구매 수

### 90일

- 24~30편 발행
- 검색 유입에서 무료판 다운로드가 실제 발생하는지 판단
- 전환이 발생한 주제와 전혀 발생하지 않은 주제 분리
- 아래 셋 중 하나 결정

| 결과 | 결정 |
|---|---|
| 검색과 전환 모두 확인 | 블로그 1개 강화, 두 번째 블로그 분리 검토 |
| 검색은 있으나 전환 없음 | CTA·무료판 약속·독자 적합성 수정 |
| 검색 자체가 거의 없음 | 키워드·제목·색인 점검 후 네이버 블로그 병행 |

## 8. 성과 지표

### 검색 지표

- 색인된 글 수
- 검색 노출과 클릭
- 글별 검색 질의
- 평균 순위보다 실제 클릭이 발생한 질의
- 업데이트 후 노출 변화

### 퍼널 지표

- CTA 클릭률 = CTA 클릭 / 해당 글 방문
- 오픈채팅 입장률 = 입장 / CTA 클릭
- 무료판 다운로드율 = 다운로드 / 입장
- 유료 전환율 = 구매 / 무료판 다운로드
- 매출 기여 글 = 구매자가 처음 또는 마지막으로 본 글

### 신뢰 지표

- 운영 기록 글의 평균 체류와 재방문
- 댓글·문의에서 반복되는 질문
- 무료판에서 이해되지 않았던 부분
- 실제 화면·수치가 있는 글과 없는 글의 차이

## 9. 하지 말아야 할 것

- 블로그 2개를 동시에 열고 같은 글을 변형해 복제하기
- AI가 만든 글을 운영자 검증 없이 매일 발행하기
- 모든 글 제목에 `부업`, `수익`, `돈 버는 법` 넣기
- 근거 없는 수익 인증과 성공 약속 사용하기
- 글 첫 화면부터 오픈채팅 링크로 밀어내기
- 애드센스 승인을 위해 의미 없는 글 수 채우기
- 다음 검색 유입 하나에 사업을 의존하기
- 티스토리에만 원본을 보관하기

## 10. 최종 제안

이 프로젝트의 가장 강한 경쟁력은 글을 잘 생성하는 AI가 아니다. 이미 존재하는 다음 자산이다.

- 실제 AI 음악 채널 3개
- 제작·발행·검수 자동화 시스템
- 실패와 수정 기록
- 곡과 영상이라는 결과물
- 매일 쌓이는 운영 데이터

강사형 콘텐츠는 성공담과 가능성을 판다. 그밤PD 블로그는 **실제로 운영하는 사람의 장부와 작업실**을 보여줘야 한다. 검색형 글이 문을 열고, 운영 기록이 신뢰를 만들고, 무료판이 작은 실행을 돕고, 유료판이 전체 시스템을 제공하는 구조가 가장 자연스럽다.

따라서 첫 90일의 목표는 광고 수익이 아니다.

> `Suno를 검색한 사람이 이 사람은 실제로 해본 사람이라고 느끼고, 다음 단계의 자료를 받기 위해 자발적으로 오픈채팅에 들어오는가?`

이 질문에 대한 증거를 얻으면 두 번째 블로그와 유료판 확장은 그다음에 결정해도 늦지 않다.
