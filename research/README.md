# Research archive

이 폴더는 2026-07-16 티스토리 전략 보고서의 조사 기록을 보관한다.

- `raw/claude-deep-research-output.txt`: Claude 심층 조사 실행 상태와 결과 미리보기
- `raw/claude-deep-research-journal.jsonl`: 완료된 조사·검증 에이전트의 원시 결과

`raw/`는 임시 세션 결과를 안전하게 복구하기 위한 로컬 자료이며 Git에는 포함하지 않는다.

최종 보고서에는 공식 문서로 재검증된 사실만 핵심 근거로 사용했다. 개인 블로그의 수익 추정, 애드센스 승인에 필요한 고정 글 수, 검증되지 않은 검색 저품질 규칙은 제외했다.
